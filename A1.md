### What It Is
This is NOT just a doctor listing website.
It is a **healthcare navigation ecosystem** — combining:

- **Doctor Discovery Engine** — search by name, specialty, city, symptoms
- **Symptom-Based Health Guidance** — tap symptom → get recommended doctors
- **Hospital & Diagnostic Center Finder** — with services, timing, maps
- **Chamber Workflow Information** — exact timing, fees, appointment contact
- **Local SEO Search Engine** — 198 city × specialty landing pages for Google
- **Community Platform** — user reviews, doctor submissions, corrections

| Network Performance    | Heavy, slow             | Optimized for 3G/4G India         |
| Coverage               | Single city             | All of North Bengal (11 cities)   |
| Structured Data        | None                    | JSON-LD schema on every page      |
| Offline Support        | None                    | PWA with offline cache            |

| Language               | English-first           | Bengali-first, bilingual          |
| Architecture           | Monolith                | Decoupled App + Admin Panel       |
| Hosting Cost           | Server cost             | Near-zero (Vercel + Supabase)     |

## A2. Brand Identity System

### Logo Concept
- **Icon:** Stylized stethoscope merged with a mountain silhouette
  (represents North Bengal / Himalayan foothills — Darjeeling, Siliguri)
- **Form:** Circular badge — professional, trustworthy, medical
- **Style:** Clean vector, 2-color (primary blue + white)
- **File formats needed:** SVG (scalable), PNG 192×192, PNG 512×512,
  PNG 512×512 maskable (for PWA)
